## 未来适配边界

保留高层运动策略与传统低层控制的分工。首版的三维速度可继续作为部署接口；具体飞控／中间件尚未选定，不预设 PX4、ROS 或通信协议为本次依赖。

| 部位 | 后续工作 |
|---|---|
| 观测 | 用实测视觉、气体及自身状态替代仿真真值；固定单位、采样和预处理 |
| 坐标 | 与部署端统一自身 yaw／世界系、轴向、四元数顺序、相机外参 |
| 偏航 | 用实际可获得的参考，不能继续自动朝未知源真值 |
| 输出 | 明确发送速度还是方向／局部航点；首版基准为速度，不自动扩展输出维数 |
| 时间与状态 | 感知和策略周期、超时处理、动作保持及循环状态 reset |
| 模型 | 导出、设备推理、端到端时延、输入丢失和数值有效性 |
| 控制器 | 仿真 Lee 与部署速度接口的响应差异；必要时加入相应延迟和动力学随机化 |

更高维方向分布或未来轨迹序列属于输出接口变更，届时另列 action_dim、解码方式、约束和 checkpoint 兼容性，不悄悄塞入首版三维速度接口。

## FlyDrones 硬件后端的后置复用

本地 drones/ 下已有 Tello、Crazyflie、MAVLink、UDP 桥等接口，可用于后续平台适配参考，首版不安装对应 SDK、不运行 send 或飞行命令。仓库 README 明确写明适配器尚未经过作者实飞验证，不能把存在 SDK 调用当作实飞证据。

MAVLink 后端把归一化 forward／lateral／throttle 转成前／右／下速度及 yaw rate；项目输出则是有明确尺度的三维速度，Lee 使用 yaw 角。适配必须处理物理单位、左右与上下符号、heading→自身航向参考、角度→角速度的控制职责，不可直接套用 MotorDecoder。

不迁入它的 SimDrone／Pilot 替代 Isaac Lab 与 Lee。具体本地代码入口见 [[06 本地代码库与复用清单]]。
